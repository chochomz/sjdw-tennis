1 시스템 개요 및 2대 접속 모드 (보안 게이트)

세종 대왕테니스 클럽은 주말 클럽 정기 모임(KDK 복식)과 대외 협회장배 단체전(3복식/5복식)을 완벽하게 통합 지원하는 실시간 경기 운영 웹 앱입니다.

A ⚡ 총무/경기이사 모드 (공식 관리자)

• 클라우드(Firebase) 실시간 동기화: 대진표 생성, 선수명 및 점수 기입 내용이 모든 접속 회원의 화면에 실시간으로 즉시 전송됩니다.
• 영구 보관 권한: 공식 경기 결과 저장, 아카이브 관리, 사진 등록 및 삭제 권한을 보유합니다.
• 입장 방법: 시작 화면에서 버튼 터치 후 보안 인증 패드(테니스공 로고)를 빠르게 7회 연속 터치하면 보안 코드가 일치되어 즉시 입장됩니다.

B 👀 일반회원 모드 (개인모드)

• 클라우드 DB 완전 보호: 일반 회원이 점수를 입력하거나 대진을 변경하더라도 클라우드 공용 DB로는 일체 전송되지 않습니다.
• 자유로운 가상 연습: 본인의 스마트폰 브라우저 세션에서만 임시 적용되며, 다른 회원이나 총무 화면에는 전혀 영향을 주지 않습니다.
• 종료 시 자동 리셋: 브라우저 창을 닫거나 상단 모드 뱃지를 터치해 나가면 가상 데이터가 자동 삭제되어 클럽 원래 데이터로 복구됩니다. 경기 결과를 보관하려면 [📸 캡처공유]로 사진을 저장하세요.

2 개인전 KDK 3대 경기 방식 상세 안내

KDK 방식이란 테니스 복식 경기에서 참가자 전원이 매 경기마다 파트너와 상대방을 바꾸어가며 경기하고, 개인별 승수와 득실차를 종합하여 개인 순위를 정하는 가장 대중적인 테니스 친선 토너먼트 방식입니다.

• 경기 시간과 체력 소모가 공평하게 배분됨 		대관 시간이 제한되어 있거나 모든 회원이 균등한 출전 기회를 원할 때
③ KDK (A·B그룹 모드) • 실력이나 등급에 따라 A그룹(상급/청룡)과 B그룹(일반/백호)으로 독립 분할
• A그룹(4~8명)과 B그룹(4~8명)의 인원수와 코트를 각각 독립적으로 설정하여 동시 운영 		회원 간 실력 편차가 크거나, 코트가 2개 이상이라 수준별 리그를 나눌 때
3 KDK [탭 1: 선수] - 선수 명단 등록 및 자동 배정
1 KDK 버전 및 인원수 선택

• 상단 좌측 드롭다운에서 KDK v2010 / KDK (4게임) / KDK (A·B그룹)을 선택합니다.
• 상단 우측에서 참가 인원(4명~16명)을 선택하면 대진표가 즉시 자동 계산되어 생성됩니다.
• A·B그룹 모드 선택 시 A그룹 인원(A:5명 4G 등)과 B그룹 인원(B:4명 3G 등)을 각각 선택하는 드롭다운으로 자동 전환됩니다.

2 초고속 Enter 키 연쇄 입력

• 1번 선수 이름을 입력한 후 키보드의 Enter 키를 누르면 다음 선수 입력칸으로 커서가 자동으로 연속 점프합니다.
• A·B그룹 모드에서는 A그룹 마지막 선수 입력 후 Enter를 누르면 B그룹 1번 칸으로 부드럽게 이어집니다.
• 선수 이름을 수정하면 대진표와 순위표에 실시간 100% 자동 동기화됩니다.

1 스마트 자동 포커스 이동 (Smart Auto-Jump)

• 1글자 입력 시 상대편 점수칸 자동 점프: 우리팀 점수를 누르면 즉시 상대팀 점수칸으로 커서가 이동하여 편리합니다.
• 세트 종료 시 다음 경기 자동 스크롤: 상대팀 점수까지 기입되면 즉시 다음 경기 점수칸으로 자동 스크롤 및 포커스되어 한 손으로 빠르게 전체 점수를 입력할 수 있습니다.
• 간편 재입력(수정): 이미 입력된 점수칸을 터치하면 기존 숫자가 전체 자동 선택(Select)되어 지우지 않고 새 숫자를 누르면 바로 덮어써집니다.

2 실시간 카드 시각화 & 관리자 버튼

• 승리/양보 자동 판정: 점수가 입력되면 승리팀 박스는 초록색(`win-box`), 패배팀은 회색(`lose-box`)으로 즉각 전환됩니다.
• 휴식자 뱃지: 해당 라운드에 쉬는 선수는 노란색 `휴식: 5-정서브` 라벨로 명확히 표시됩니다.
• 대진 재배정: `[대진재배정]` 버튼으로 기존 결과를 초기화하고 새로운 매칭 알고리즘으로 대진표를 짤 수 있습니다.

7 단체전 [탭 1: 선수명단] - 복식 조별 페어 및 후보 등록
1 경기 방식 (3복식 / 5복식) & 팀 선택

• 3복식 (3전 2선승): 1조, 2조, 3조 각 2명(총 6명) + 후보 2명 입력
• 5복식 (5전 3선승): 1조~5조 각 2명(총 10명) + 후보 2명 입력
• 상단 드롭다운에서 A팀 / B팀 / C팀을 변경하여 각 팀의 출전 명단을 독립적으로 등록합니다.

2 모든 라운드 자동 연동 (Auto-Sync)

• 선수명단 탭에서 이름을 한 번만 등록해 두면, 예선부터 결승전까지 모든 라운드 경기 카드의 우리팀 선수명단으로 자동 연동됩니다.
• 라운드 진행 중 부상이나 전략 변경으로 특정 경기에서만 선수가 바뀐 경우, 해당 라운드 경기 카드에서 개별 수정도 완벽히 지원합니다.

• 예선 1경기부터 결승전까지 8개 라운드가 카드 형태로 진출 현황을 한눈에 보여줍니다.
• 승리한 라운드는 녹색(`node-win`), 패배는 붉은색(`node-lose`), 대기는 회색으로 표시됩니다.
• 로드맵 노드를 터치하면 해당 라운드 경기 화면으로 즉시 점프하여 상세 경기 결과를 검토할 수 있습니다.

2 최종 성적 자동 추천 저장 모달

• [💾 대회저장]을 누르면 결승 승리 시 '🏆 우승', 결승 패배 시 '🥈 준우승', 4강 패배 시 '4강' 등 최종 도달 성적을 시스템이 자동 추천하여 선택해 줍니다.
• 저장된 단체전 기록은 [📂 불러오기]에서 우승/준우승 뱃지와 함께 보관되며 언제든 다시 열람할 수 있습니다.

10 파이어베이스 실시간 동기화 & 동시 입력 충돌 방지 구조

대회 당일 여러 회원이 동시에 스마트폰을 켜고 각 코트의 점수를 입력하거나 다른 팀 경기를 입력할 때, 데이터 덮어쓰기나 입력 끊김이 발생하지 않도록 정밀한 동시성 제어 기술이 적용되어 있습니다.

🔒 팀 단위 원자적 업데이트

A팀, B팀, C팀을 입력할 때 전체 문서를 통째로 덮어쓰지 않고, teams.A, teams.B, teams.C 개별 필드만 독립 저장하므로 동시에 다른 팀 점수를 입력해도 서로의 내용이 지워지지 않습니다.

⌨️ 타이핑 중 포커스/DOM 보호

내가 점수나 선수명을 타이핑하고 있는 도중에 다른 사람의 입력 데이터가 클라우드로 수신되더라도, 현재 타이핑 중인 입력창의 DOM을 재생성하지 않아 스마트폰 키보드가 내려가거나 입력이 중단되는 현상을 원천 방지합니다.

📱 기기별 독립 화면(View) 유지

다른 사람이 자기 기기에서 B팀이나 8강전으로 화면을 전환하더라도, 내 기기에서 보고 있던 A팀 예선 화면이 강제로 바뀌지 않도록 로컬 뷰 상태가 완벽히 독립 보장됩니다.

12 자주 묻는 질문(FAQ) 및 트러블슈팅
Q1. 일반회원이 입력한 내용이 왜 다른 사람한테는 안 보이나요?

일반회원(개인모드)은 공식 클럽 데이터베이스(DB)를 안전하게 보호하기 위해 내 기기에서만 가상으로 동작하는 샌드박스 연습 모드로 동작합니다. 공식 대회 점수를 기록하려면 총무/경기이사 모드로 로그인하셔야 합니다.

Q2. 상단 시계 옆의 초록불, 파란불, 빨간불은 무슨 뜻인가요?

• 🟢 초록불: 파이어베이스 클라우드와 정상 연결되어 실시간 공유 중입니다.
• 🔵 파란불(깜빡임): 입력하신 점수나 선수명이 클라우드에 저장되는 중입니다.
• 🔴 빨간불: 인터넷 연결이 끊겼거나 개인모드 상태입니다.

Q3. 동점자가 생겼을 때 순위는 어떻게 결정되나요?

테니스 공식 규정에 따라 1. 승수(승리 경기 수) ➔ 2. 득실차(총 득점 - 총 실점) ➔ 3. 다득점 ➔ 4. 승률 순으로 자동 판별되어 공정하게 순위가 매겨집니다.

Q4. 잘못된 경기 점수를 고치고 싶어요.

수정하고 싶은 점수 칸을 가볍게 터치하면 기존 숫자가 전체 선택됩니다. 백스페이스(지우기)를 누를 필요 없이 바로 새 숫자를 누르면 즉시 덮어써지며, 순위표와 진출 현황도 실시간 재계산됩니다.
